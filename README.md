## 🚀 Featured Projects

### 💰 PLATA — Loan Management System
**Personal project • Full-Stack Developer**

A web platform to manage clients, loan contracts, installments and payments.

**Key Features**
- REST API built with Django REST Framework and token authentication
- Automatic installment generation, interest and payoff calculation
- Payment registration with atomic transactions and row-level locking
- Custom visual identity with a dark theme and canvas animations
- Deployed on Vercel with a PostgreSQL database on Neon

**Stack:** Python • Django • Django REST Framework • PostgreSQL • Vercel

### 🗳️ Live Election Results — Brazil 2026
**Personal project • Full-Stack Developer** · [apuracaoaovivo.com.br](https://apuracaoaovivo.com.br)

A free, mobile-first website to follow Brazil's 2026 election results in real time, by state, using official data from the Superior Electoral Court (TSE). Built for people who are away from a TV when the count starts.

**Key Features**
- Real-time results filtered by state
- Hosted on AWS EC2 behind Nginx, with Cloudflare for DNS, proxy and SSL

**Stack:** AWS (EC2, IAM) • Nginx • Cloudflare • Linux
